**Lumen Bastion** is a neon arena-defense game: you are the guardian of the Ember Core, a light that must not go out. Waves of hostiles — darting strikers, long-range spitters, armored bulwarks, and every fifth wave a Warden boss — close in on the core. Move with WASD or the arrow keys, aim with the mouse, hold click or Space to fire. Kills drop shards; between waves you pick one of three upgrades (split shot, piercing rounds, core repair, combo surge, and more) and push on. Survive all 15 waves to win. Pure Canvas 2D and hand-synthesized WebAudio sound effects — no libraries, no audio files, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
